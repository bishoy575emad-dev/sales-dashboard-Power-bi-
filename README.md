# Sales Analytics Dashboard – Power BI
An interactive 3-page Power BI dashboard built on Adventure Works data, covering sales performance, customer behavior, and product analytics.

---

## Dashboard Pages

### 1. Sales Overview
- Total customers, orders, revenue, profit, and return rate
- Top model by orders & top product by revenue
- Monthly revenue, return rate, and profit trends
- Product performance summary table

### 2. Customer Insights
- Revenue segmented by education level, occupation, and gender
- Top 10 customers by revenue
- Average revenue per customer

### 3. Product Analytics
- Revenue breakdown by category (Bikes, Accessories, Clothing)
- Revenue trends by year and category (2020–2022)
- Top 10 products by profit margin, revenue, and return rate

---

## Tools Used
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Data Modeling

## Data Source
Adventure Works – Microsoft sample dataset
